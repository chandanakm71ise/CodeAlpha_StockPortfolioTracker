# Stock Portfolio Tracker

## About
A simple Python-based Stock Portfolio Tracker that allows users to manage their stock holdings and calculate portfolio information.

## Features
- Add stocks
- View stock details
- Track quantity and price
- Calculate investment value
- Simple and easy-to-use Python program

## Technologies Used
- Python
- Object-Oriented Programming
- Dictionary
- Arithmetic operations

## How to Run
1. Download or clone this repository.
2. Open `stocktracker.py` in Python or VS Code.
3. Run the program.
